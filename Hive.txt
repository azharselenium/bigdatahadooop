Step 1: Verify Hadoop is Running
Check:

jps
Expected:

NameNode
DataNode
SecondaryNameNode
ResourceManager
NodeManager
Verify HDFS:

hdfs dfs -ls /
If this works, Hadoop is ready for Hive.

Step 2: Download Hive
Go to:

Apache Hive Downloads

Or download via terminal:

wget https://archive.apache.org/dist/hive/hive-4.0.1/apache-hive-4.0.1-bin.tar.gz

Extract:

tar -xzvf apache-hive-4.0.1-bin.tar.gz
Move:

sudo mv apache-hive-4.0.1-bin /opt/hive

Step 3: Configure Environment Variables
Edit:

nano ~/.bashrc
Add:

export HIVE_HOME=/opt/hive
export PATH=$PATH:$HIVE_HOME/bin

export HADOOP_HOME=/usr/local/hadoop
export HADOOP_MAPRED_HOME=$HADOOP_HOME
Reload:

source ~/.bashrc
Verify:

echo $HIVE_HOME

Step 4: Create Hive Configuration
Go to Hive config folder:

cd $HIVE_HOME/conf
Copy template:

cp hive-default.xml.template hive-site.xml

Step 5: Configure Hive Metastore
For learning/lab purposes use Derby.

Create:

nano hive-site.xml
Add:

<configuration>

<property>
  <name>javax.jdo.option.ConnectionURL</name>
  <value>jdbc:derby:;databaseName=metastore_db;create=true</value>
</property>

<property>
  <name>hive.metastore.warehouse.dir</name>
  <value>/user/hive/warehouse</value>
</property>

</configuration>

Step 6: Create Warehouse Directory in HDFS
Create:

hdfs dfs -mkdir -p /user/hive/warehouse
Grant permissions:

hdfs dfs -chmod g+w /user/hive/warehouse
Verify:

hdfs dfs -ls /user/hive
Expected:

warehouse

Step 7: Download PostgreSQL Driver (Hive 4.x Requirement)
Many Hive versions need JDBC dependencies.

Create lib directory if needed:

mkdir -p $HIVE_HOME/lib
If using Derby bundled with Hive you may skip this for training labs.

Step 8: Initialize Hive Schema
Run:

schematool -dbType derby -initSchema
Expected:

Initialization script completed
If successful, Hive metastore is created.

Step 9: Start Hive
Launch:

hive
Expected:

hive>

Step 10: Verify Hive
Show databases:

SHOW DATABASES;
Output:

default
Lab Exercise 1: Create Database
CREATE DATABASE company;
Verify:

SHOW DATABASES;
Output:

default
company
Lab Exercise 2: Use Database
USE company;
Lab Exercise 3: Create Table
CREATE TABLE employee(
id INT,
name STRING,
salary FLOAT
);
Check:

SHOW TABLES;
Lab Exercise 4: Insert Data
INSERT INTO employee VALUES
(1,'Radhika',50000),
(2,'Azhar',65000),
(3,'John',75000);
Lab Exercise 5: Query Data
SELECT * FROM employee;
Output:

1 Radhika 50000
2 Azhar   65000
3 John    75000
Lab Exercise 6: Aggregation
SELECT AVG(salary)
FROM employee;
Output:

63333.33
Lab Exercise 7: Create CSV-Based Table
Create CSV:

nano employee.csv
1,Radhika,50000
2,Azhar,65000
3,John,75000
Create Hive table:

CREATE TABLE emp_csv(
id INT,
name STRING,
salary INT
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ',';
Load CSV:

LOAD DATA LOCAL INPATH
'/home/hadoop/employee.csv'
INTO TABLE emp_csv;
Verify:

SELECT * FROM emp_csv;
