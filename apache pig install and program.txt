Installing Apache Pig on macOS is quick using Homebrew, which automatically resolves dependencies like Java.
1. Prerequisites
Ensure you have Homebrew installed on your Mac. You will also need a Java Development Kit (JDK) installed and configured since Pig is a Java-based application.
2. Install Apache Pig
Open your Terminal and run the following Homebrew command to install Pig:
bash
brew install pig


3. Set Environment Variables
Pig needs to know where Java is installed on your system. You can set the JAVA_HOME variable by updating your shell configuration file (e.g., ~/.zshrc if you are using macOS Catalina or later).
Open your shell profile in a text editor:
bash
nano ~/.zshrc


Add the following lines to the bottom of the file (adjust openjdk to your installed Java version if different):
bash
export JAVA_HOME="/opt/homebrew/opt/openjdk"
export PATH="$JAVA_HOME/bin:$PATH"


1. Save and close the file (in nano, press Ctrl+O, Enter, then Ctrl+X).
Apply the changes:
bash
source ~/.zshrc


4. Verify Installation
To confirm that Apache Pig is successfully installed, check the version:
bash
pig -version

Create a Symlink 
We can simply trick the homebrew runner by creating a shortcut link with the exact name it is demanding. Run this command in your Terminal:
bash
ln -s /opt/homebrew/opt/pig/libexec/pig-0.18.0-core-h3.jar /opt/homebrew/opt/pig/libexec/pig-core-h.jar


Now try typing pig -version. It will instantly recognize the file and initialize the Grunt shell.

2. Run a Quick "Hello World" (Word Count) 
Let’s test Pig by creating a small text file and counting how many times each word appears.
Step A: Create a Sample File
Open a new Terminal window (keep Grunt open in your other one) and create a simple text file:
bash
echo "apple banana apple cherry banana apple" > ~/Documents/sample.txt




Step B: Run the Pig Latin Script [1]
Switch back to your Grunt shell (grunt>) and run these commands line by line: [1]
pig
-- 1. Load the data from your local documents folder
lines = LOAD '~/Documents/sample.txt' AS (line:chararray);


-- 2. Tokenize the sentences into individual words
words = FOREACH lines GENERATE FLATTEN(TOKENIZE(line)) AS word;


-- 3. Group identical words together
grouped = GROUP words BY word;


-- 4. Count the occurrences of each word
word_counts = FOREACH grouped GENERATE group AS word, COUNT(words) AS count;


-- 5. Print the results to your screen
DUMP word_counts;


-- 6. Save directly to a folder instead of printing to screen 
STORE word_counts INTO '/Users/azharjamal/Desktop/pig_output';


How to View Your Results
Once the script says Success!, open your standard Mac Terminal (or use Finder) and look inside the newly created folder to see your results:
bash
cat /Users/azharjamal/Desktop/pig_output/part-r-00000




Once the MapReduce logs finish printing, you should see an output like this:
text
(apple,3)
(banana,2)
(cherry,1)
